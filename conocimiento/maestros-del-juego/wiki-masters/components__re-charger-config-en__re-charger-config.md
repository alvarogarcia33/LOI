## Re-charger Config
Booster Re-charger Config
Type: trainable
Training duration: 3 days
Requires: Re-charger
A special tool designed to improve the Advisor's parameters in the Legends of Interactions game universe .
With this booster, the Advisor automates the recharging process using batteries, allowing for the recharging of the Master’s of Game advertising orbs , such as BILLBOARD and MAPS.
Unlike the regular Re-charger , this booster is customizable. The Master of Game can specify which orbs should be recharged and which should not. Additionally, the Master of Game can set a maximum number of batteries that the Advisor is allowed to use. This feature allows the Master of Game to manage his/her game objects more rationally and effectively.
