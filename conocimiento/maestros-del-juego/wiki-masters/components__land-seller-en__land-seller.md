## Land Seller
Booster Land Seller
Type: standard
A special tool designed to improve the Advisor's parameters in the Legends of Interactions game universe .
It allows the Master of Game to list all of the owned plots of land for sale on the Marketplace at a price set by the Master of Game.
In this case, there is no need to list each plot on the Marketplace separately, which allows saving a lot of time.
